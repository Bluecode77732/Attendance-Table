출석부 사용 설명서

학생이 학원에 둔 출석 기기(갤럭시)에 휴대폰번호 뒷 4자리를 누르면, TV 현황판에 등원과 하원이 바로 나타나요. 날짜별 기록은 상담할 때 인쇄해 볼 수 있어요.

1. 교사 PC 준비 (처음 한 번)

  1. 받은 zip 파일을 바탕화면 같은 일반 폴더에 압축 해제해 주세요. zip 안에서 바로 실행하면 동작하지 않아요.
  2. 풀린 폴더에서 start.bat을 더블클릭해 주세요. 처음 실행하면 바탕 화면에 "출석부" 바로 가기가 생겨요. 다음부터는 그것을 더블클릭해 주세요.
  3. Windows 보안(방화벽) 창이 뜨면 "액세스 허용"을 눌러 주세요. 한 번 뜨는 게 정상이고, 허용해야 출석 기기가 접속할 수 있어요.
    허용 버튼이 눌리지 않거나, 창이 뜨지 않았는데 출석 기기가 접속되지 않으면 PC를 관리하는 분께 "이 PC의 node.exe가 8080번 포트로 들어오는 접속을 허용하게 해 주세요"라고 요청해 주세요.
  4. 검은 창이 하나 열리고, 잠시 뒤 브라우저에 출석부 화면이 자동으로 열려요. 검은 창 첫 줄의 Node v… (AMD64) 같은 글은 이 PC에 맞는 실행 파일을 골랐다는 표시예요. 문의할 때 이 줄을 알려 주세요.
    검은 창과 출석부 화면은 수업 중에 닫지 마세요. 검은 창이 출석부 서버라서 닫으면 꺼져요. 출석부 화면(현황판과 기록 창)을 모두 닫아도 5초 뒤 출석부가 꺼지고 검은 창도 닫혀요. 최소화와 새로고침(F5)은 괜찮아요.
  5. 브라우저에서 F11을 누르면 전체 화면이 돼요. PC 화면을 TV에 연결(HDMI 등)해서 띄워 주세요.
  6. PC를 켜면 출석부도 저절로 켜지게 하기: Windows + R을 누르고 shell:startup을 입력해 열리는 폴더에, start.bat을 마우스 오른쪽 버튼으로 끌어다 놓고 "바로 가기 만들기"를 골라 주세요.
출석부 화면은 교사 PC의 브라우저(주소 http://localhost:8080)에서만 열려요. 출석 기기나 다른 PC에서는 열리지 않아요.

2. 학생 명단 넣기 (처음 한 번)

  1. 구글 스프레드시트(또는 엑셀)에서 Ctrl + A로 전체를 선택하고 Ctrl + C로 복사해 주세요. 제목 줄까지 함께 복사돼요.
  2. 출석부 화면 위쪽의 "명단 붙여넣기"를 누르고, 입력칸에 Ctrl + V로 붙여넣어 주세요.
  3. "미리보기"를 눌러 추가될 학생과 건너뛸 학생을 확인한 뒤, "추가하기"를 눌러 주세요.
  • 제목 줄에 '이름' 칸은 꼭 있어야 해요. '번호'나 '휴대폰', '반'이나 '타임' 칸이 있으면 같이 가져와요. 학교, 학년 같은 다른 칸은 가져오지 않아요.
  • 번호나 반 칸이 없어도 괜찮아요. 붙여넣은 뒤 학생마다 "정보"에서 입력하면 돼요. 미리 시트에 '휴대폰'과 '타임' 칸을 추가해 두면 한 번에 들어가요.
  • 반 칸에 여러 반을 쓰려면 쉼표로 나눠 주세요. 예: 3시 타임, 7시 타임
  • 이미 명단에 있는 이름은 건너뛰어요. 붙여넣은 목록에 없는 학생을 지우지는 않아요. 그래서 나중에 신입생이 생기면 다시 붙여넣어도 돼요.
  • 학생이 아주 많으면 "한 번에 붙여넣기에는 너무 많습니다"라고 나와요. 두세 번에 나눠서 붙여넣어 주세요.
출석은 휴대폰번호가 있는 학생만 할 수 있어요. 번호가 없는 학생 칸에는 왼쪽 위에 "번호 없음"이 보여요. 번호는 TV에도 보이니, 학생이 TV를 보지 않을 때 입력해 주세요.

3. 출석 기기(갤럭시) 준비 (처음 한 번)

  1. 갤럭시를 교사 PC와 같은 학원 Wi-Fi에 연결하고, 충전기를 꽂아 두세요.
  2. 교사 PC 출석부 화면에서 "출석 기기"를 누르면 QR과 주소가 나와요. 갤럭시 카메라로 QR을 찍거나, 갤럭시 브라우저에 그 주소를 입력해 주세요.
  3. 갤럭시에 "출석 기기 등록" 화면이 나오면, 교사 PC에서 "등록 코드 받기"를 누르고 나온 6자리 숫자를 갤럭시에 눌러 주세요. 코드는 10분 동안만 쓸 수 있어요.
  4. "등록됐어요"가 나오면 끝이에요. 브라우저 메뉴에서 홈 화면에 추가해 두면 다음부터 바로 열 수 있어요.
  5. 화면이 꺼지지 않게
    1. 설정 → 휴대전화 정보 → 소프트웨어 정보에서 "빌드 번호"를 7번 눌러 주세요. 잠금 PIN을 물으면 입력해 주세요. 개발자 모드가 켜졌다는 안내가 나오면 돼요.
    2. 설정 맨 아래에 생긴 "개발자 옵션"에서 "화면 켜짐 상태 유지"를 켜 주세요. 기종에 따라 "충전하는 동안 화면 켜짐"처럼 이름이 조금 달라요.
    3. 화면을 하루 종일 켜 두면 화면에 자국이 남을 수 있어요. 화면 밝기를 낮춰 두세요.
  6. 학생이 다른 앱으로 넘어가지 않게
    1. 설정 → "보안 및 개인정보 보호"(예전 기종은 "생체 인식 및 보안") → "기타 보안 설정" → "앱 고정"을 켜 주세요.
    2. 출석 화면을 연 채로 최근 앱 버튼을 누르고, 출석 화면 위쪽의 앱 아이콘을 눌러 "이 앱 고정"을 골라 주세요.
    3. 고정을 풀 때는 뒤로 가기 버튼과 최근 앱 버튼을 함께 길게 눌러 주세요.
갤럭시 설정 메뉴 이름과 위치는 기종과 버전마다 조금 달라요. 찾기 어려우면 설정 화면 위쪽의 검색에 "빌드 번호", "화면 켜짐", "앱 고정"을 입력해 보세요.

4. 학생이 출석하는 법

  1. 출석 기기에 휴대폰번호 뒷 4자리를 눌러요. 4자리를 다 누르면 바로 처리돼요.
  2. 그날 처음 누르면 등원, 다음에 누르면 하원이에요. 하원한 뒤 다시 오면 또 등원으로 기록돼요.
  3. 화면에 "○○○ 등원했어요"와 시각이 나오면 끝이에요. 몇 초 뒤 다음 학생을 위해 키패드로 돌아가요.
  • 같은 번호를 쓰는 학생이 여럿이면(형제자매가 부모님 번호를 쓰는 경우 등) 이름을 고르는 화면이 나와요.
  • 누르고 10분 안에 다시 누르면 "이미 등원했어요"처럼 나오고 아무것도 바뀌지 않아요. 두 번 눌러서 하원 처리되는 일을 막기 위해서예요.

5. TV 현황판 보기와 조작

칸 색: 회색 = 미등원, 초록 = 등원(등원 시각 표시), 빨강 = 하원(하원 시각 표시)

하고 싶은 일방법
반(타임)별로 보기위쪽의 반 선택에서 반을 골라 주세요. "전체"를 고르면 모든 학생이 보여요.
학생 출석을 직접 바꾸기그 학생의 칸을 눌러 주세요. 누를 때마다 지금 시각으로 미등원 → 등원 → 하원 → 다시 등원 순서로 넘어가요. 잘못 눌렀으면 "기록 보기"에서 그 시각을 지워 주세요.
이름 고치기칸에 마우스를 올리면 오른쪽 위에 버튼이 나타나요. ✎를 눌러 이름을 쓰고 Enter를 눌러 주세요. 취소는 Esc, 최대 12자예요.
번호, 반 바꾸기칸의 "정보"를 눌러 번호를 쓰고 "번호 저장"을 눌러 주세요. 반은 체크하면 바로 저장돼요. 같은 번호의 학생이 있으면 알려 주지만 막지는 않아요.
학원을 그만둔 학생"정보"에서 "퇴원 처리"를 눌러 주세요. 현황판과 출석 기기에서 빠지고 번호는 지워져요. 지난 기록은 남아요. 다시 다니게 되면 위쪽 "퇴원생"에서 "복귀"를 누르고 번호를 다시 넣어 주세요.
잘못 등록한 학생 지우기칸의 ✕를 누르고 확인해 주세요. 그 학생의 출석 기록도 함께 지워지고 되돌릴 수 없습니다. 그만둔 학생은 삭제하지 말고 퇴원 처리해 주세요.
학생 한 명 추가마지막 페이지의 점선 "+ 학생 추가" 칸을 누르고 이름을 써 주세요. 반을 고른 상태면 그 반에 들어가요.
반 만들기, 이름 바꾸기, 지우기위쪽 "반 관리"에서 해 주세요. 반을 지워도 학생은 그대로 있고 그 반 표시만 빠져요.
다음/이전 페이지키보드 ← → 또는 오른쪽 위의 ‹ › 버튼. 한 페이지에 8명씩 보여요.
학원 이름 넣기, 고치기위쪽 줄 왼쪽의 "학원 이름 넣기"(이름을 넣은 뒤에는 그 이름)를 눌러 이름을 쓰고 Enter를 눌러 주세요. 취소는 Esc, 최대 15자예요. 이름은 현황판, 출석 기기 위쪽 띠, 기록 인쇄 제목에 나와요. 출석 기기에는 다음 출석부터 바뀐 이름이 보여요. 칸을 비우고 저장하면 이름이 지워져요.
위쪽 줄 접기 (수업 중)위쪽 줄 가운데 아래의 "▲ 접기"를 누르면 줄이 위로 올라가고 학생 칸이 커져요. 다시 보려면 맨 위 가운데의 "▼ 펼치기"를 눌러 주세요. 접어도 페이지는 ← →로 넘길 수 있어요. 출석부를 새로 열면 펼쳐진 채로 시작해요.

위쪽 줄 오른쪽에는 오늘 날짜와 지금 시각이 나와요. 이 PC의 시계를 따라요.

6. 기록 보기와 인쇄 (상담용)

  1. 위쪽의 "기록 보기"를 누르면 새 창에 한 달 표가 열려요. 학생마다 날짜 칸에 등원–하원 시각이 들어 있고, 맨 끝에 출석일 수가 있어요.
  2. ‹ ›로 달을 옮기고, 반 선택으로 반별로 볼 수 있어요.
  3. 기록 창은 열어 둔 동안 저절로 바뀌지 않아요. 그사이 학생을 추가했거나 출석이 들어왔으면 위쪽의 "새로고침"을 눌러 주세요.
  4. 시각을 고치려면 그 칸을 눌러 주세요. 등원·하원 시각을 바꾸거나, "방문 추가"로 한 줄을 더하거나, "삭제"로 지운 뒤 "저장"을 눌러 주세요.
  5. "인쇄"를 누르면 A4 가로로 인쇄돼요.
기록이 없는 날은 결석이에요. 학생이 하원을 누르지 않고 갔다가 나중에 다시 누르면, 그 나중 시각이 하원으로 기록돼요. 이런 날은 기록 화면에서 고쳐 주세요.

7. 문제가 생겼을 때

증상확인할 것
출석 기기에 "출석부와 연결되지 않아요"
  • 교사 PC와 검은 창이 켜져 있나요? 출석부 화면을 모두 닫으면 출석부도 꺼져요. 바탕 화면의 "출석부"를 더블클릭해 다시 켜 주세요.
  • 갤럭시가 학원 Wi-Fi에 연결돼 있나요? 모바일 데이터만 켜져 있으면 안 돼요.
  • 교사 PC의 주소가 바뀌었을 수 있어요. 교사 PC에서 "출석 기기"를 눌러 QR을 다시 찍어 주세요. 그래도 안 되면 같은 창의 "열리지 않으면: 다른 주소로 바꾸기"를 누르고 다시 찍어 주세요(이 버튼은 주소가 여러 개일 때만 보여요).
  • 1번의 방화벽 "액세스 허용"을 했는지 확인해 주세요.
  • 공유기에 "기기끼리 통신 차단"(무선 격리, 게스트 네트워크 등) 설정이 켜져 있으면 갤럭시가 PC에 닿지 않아요. 원장님이나 인터넷 설치 업체에 문의해 주세요.
"등록되지 않은 번호예요"그 학생의 "정보"에 번호가 들어 있는지, 퇴원 처리되지 않았는지 확인해 주세요.
"코드가 맞지 않습니다" / "코드가 만료됐습니다"교사 PC "출석 기기"에서 "등록 코드 받기"를 다시 눌러 새 코드를 입력해 주세요. 5번 틀리면 그 코드는 버려져요.
"이 기기의 등록이 취소됐습니다"교사 PC에서 그 기기를 "등록 취소"한 거예요. 다시 쓰려면 새 등록 코드를 입력해 주세요.
"출석 기기를 더 등록할 수 없습니다"출석 기기는 20대까지 등록돼요. 교사 PC "출석 기기" 창에서 쓰지 않는 기기를 "등록 취소"한 뒤 다시 등록해 주세요.
출석 기기를 바꿨거나, 브라우저 기록을 지웠어요새 기기에서 3번처럼 다시 등록해 주세요. 쓰지 않는 기기는 "출석 기기" 목록에서 "등록 취소"를 눌러 주세요.
현황판 아래에 "서버와 연결이 끊겼어요"검은 창을 닫았거나, 출석부 화면을 모두 닫아 출석부가 꺼진 거예요. 바탕 화면의 "출석부"를 더블클릭해 다시 켜 주세요. 저장된 출석은 그대로예요.
검은 창에 "포트 8080을(를) 이미 쓰고 있습니다"출석부가 이미 켜져 있는 거예요. 열려 있는 출석부 창을 찾아 쓰거나, 검은 창을 모두 닫고 다시 시작해 주세요.

8. 끝낼 때와 백업

  • 끝내기: 출석부 화면(현황판과 기록 창)을 모두 닫으면 5초 뒤 출석부가 꺼지고 검은 창도 닫혀요. 검은 창을 닫아도 꺼져요. 명단과 기록은 자동 저장돼서, 다음에 켜면 그대로 이어져요.
  • 저장 위치: 같은 폴더의 data.json에 학원 이름, 학생 이름, 번호, 반, 출석 기록이 저장돼요.
  • 자동 백업: 하루에 한 번, 그날 처음 저장하기 전에 backup 폴더에 날짜 이름(예: data-2026-11-03.json)으로 복사해 두고, 최근 30개만 남겨요. PC가 고장 나면 백업도 함께 잃으니, 가끔 backup 폴더를 USB에 복사해 두면 더 안전해요.
  • 백업으로 되돌리기: 검은 창을 닫고, data.json을 다른 이름으로 바꿔 둔 뒤, backup 폴더의 원하는 날짜 파일을 출석부 폴더로 복사해 이름을 data.json으로 바꾸고 다시 시작해 주세요. 그 날짜 이후의 기록은 사라지니 주의해 주세요.
  • data.json이 깨졌을 때는 data.json.broken-…라는 이름으로 따로 보관하고 빈 명단으로 시작해요. 이때는 위 방법으로 백업을 되돌려 주세요.

9. 학원 밖에서 보기

출석부는 인터넷으로 열리지 않아요. 밖에서 노트북이나 휴대폰으로 보려면 교사 PC에 Chrome 원격 데스크톱을 설치해 교사 PC 화면을 그대로 보는 방법을 써요. 설치는 납품할 때 함께 해 드려요.

  • 노트북 Chrome에서 remotedesktop.google.com/access를 열고, 교사 PC를 고른 뒤 PIN을 입력해 주세요.
  • 휴대폰은 "Chrome 원격 데스크톱" 앱을 설치하고, 교사 PC와 같은 구글 계정으로 로그인한 뒤 교사 PC를 고르고 PIN을 입력해 주세요.
  • 교사 PC가 켜져 있고 인터넷에 연결돼 있어야 해요.
  • 접속하면 교사 PC 전체를 조작할 수 있으니 PIN은 다른 사람에게 알려 주지 마세요. 마우스를 움직이면 TV에도 보일 수 있어요.
  • 원격으로 보는 화면은 교사 PC 화면 그대로라서 TV에도 똑같이 나옵니다. 수업 중에는 현황판만 보고, "기록 보기"와 학생 칸의 "정보"는 수업이 끝난 뒤에 열어 주세요.
  • 학생 칸을 누르면 등원이나 하원으로 기록됩니다. 잘못 눌렀으면 "기록 보기"에서 그 시각을 지워 주세요.
  • 원격으로 현황판이나 기록 창을 닫지 마세요. 교사 PC의 출석부 화면이 모두 닫히면 출석부가 꺼져서 출석 기기도 멈춰요.

10. 알아 두세요

  • 학생 이름, 번호, 출석 기록은 이 PC에만 저장되고 인터넷으로 나가지 않아요.
  • 출석 기기는 등록한 기기에서만 쓸 수 있어요. 학원 Wi-Fi에 연결된 다른 기기로는 출석할 수 없어요.
  • 대리 출석을 완전히 막지는 못합니다. 다른 학생의 번호 뒷 4자리를 알면 출석 기기에서 대신 누를 수 있어요. 출석 기기를 선생님이 볼 수 있는 곳에 두어 주세요.
  • TV에는 학생 이름과 출석 상태가 보여요. 번호를 입력할 때는 번호도 TV에 보여요.
